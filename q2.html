How the Action attribute works

... in my own words

The action attribute tells a form where to send its data when the user clicks submit. Its value is a URL, usually a server script or a service like FormBucket that receives and processes the information. It works together with the method attribute, which decides how the data is sent (GET adds it to the URL, POST sends it in the background). If the action attribute is left out, the form sends the data back to the same page it is on.
